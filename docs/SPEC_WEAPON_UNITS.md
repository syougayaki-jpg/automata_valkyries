# 兵器ユニット 設計書 (SPEC_WEAPON_UNITS.md)

> 2026-10-03 作成。元仕様は既存仕様書 §7.1（ルミナルコア）・§7.2（兵装モジュール）・§7.3（背部ユニット）・§7.4（外装フレーム）・§7.5（ロジックチップ）・§7.7（ボス素材）。
> 元仕様に無い部分（使い手・電力・製造・操作・見た目など）を、ユーザーに確認して決めた内容をここにまとめる。数値の出典が無いものは【提案】と書く。

## 1. 決めたこと（2026-10-03 にユーザーが回答）

| 項目 | 決定 |
|---|---|
| 使い手 | **プレイヤーも兵姫も使える**（§8.3 のジャンク兵装と同じ）。今はプレイヤーが使い、兵姫ができたら兵姫にも持たせる。重量・ロジックチップは兵姫のときだけ効く |
| 電力 | **内蔵バッテリー＋コア**。兵装ごとに FE を蓄え、マシンで充電できる。兵姫はコアスロットのルミナルコアから、プレイヤーは持ち物のルミナルコア・バッテリーから足りない分を引く |
| 内蔵バッテリーの大きさ | 通常の兵装は**約 20 回分**、超兵器は**約 5 回分**（例: フォトンエッジ 40,000 FE、リニアレールライフル 500,000 FE、カタストロフ・バスター 5,000,000 FE） |
| 製造 | **専用の兵装製造マシンを新しく作る**: クロノリンク・マシンの **7 種目**（T1〜T4、フレーム・アップデートキット・宇宙の UI は他のマシンと同じ）。ティアが高いほど上位の兵装を作れる |
| ティアの割り振り | **T1**: フォトンエッジ・リニアレールライフル・ネクロシス・ニードルガン・偏光ディフレクター・戦術リペアインジェクター / **T2**: ルクシオンセイバー・重粒子収束砲 / **T3**: タイムエリミネイター・アイギス / **T4**: カタストロフ・バスター |
| 保護対象への効き方 | **特性は普通に効くが、保護対象（Eprotect: エレノア等のボス）には上限・拒否がそのまま掛かる**。「無敵時間無視」「999 固定」「全バフ消去」でもボスは一撃で倒せない |
| ボス素材 | **先にボス素材を登録して、レシピで要求する**。ボスができるまでは**クリエイティブ限定**（クリエイティブのタブ・コマンドだけ。敵ドロップ素材と同じ扱い）。ボスを実装したらドロップにする |
| 見た目 | **3D モデル（GeckoLib）**。剣・銃・盾ごとにモデルとアニメーション |
| 操作（プレイヤー） | **弓と同じく右クリック長押しでチャージ、離して発射**（重粒子収束砲 1.5 秒・カタストロフ・バスター 3 秒）。**両手兵装はオフハンドが空のときだけ使える**。副兵装（盾など）はオフハンドで右クリックして展開 |
| 弾薬 | **弾薬アイテム＋FE**: リニアレールライフルは徹甲弾（内部 12 発、持ち物から装填）と 1 射ごとの FE を使う |
| ブロックの破壊 | **既定はオフ、設定で有効にできる**（カタストロフ・バスターの空間崩壊などの範囲兵装。オフのときはエンティティにだけ効く） |
| 強い状態異常のプレイヤーへの適用 | **設定で切り替え**。既定は mob・ボスだけ（ネクロシス・ニードルガンの黒死侵食 = 最大 HP の永続減少 最大 30%、タイムエリミネイターの因果停止 = 3 秒の行動不能、全バフ消去）。永続減少は対象が死ぬと消える |
| 最初に作る範囲 | **兵装（§7.2 のメイン・オフハンド）とルミナルコア（§7.1）から**。背部ユニット（§7.3）・外装フレーム（§7.4）・ロジックチップ（§7.5）は後 |

### 3.2 ボス素材（`registry/ModBossDrops`、クリエイティブ限定）

`boss_drop_ftl_accel`・`luxion_core`・`gallia_plate`・`distortion_gen`・`necro_colony`・`memento_wings`・`time_needle`（16 個まで重なる）、
`ruler_heart`・`memory_stella`・`purified_zero`・`singularity_remnant`（1 個ずつ）。レア度は EPIC で、エンチャントの光が付く。ツールチップに落とすボスの名前と 2 行のフレーバーテキスト（`item/BossDropItem`、`boss.automata_valkyries.<boss>`・`<id>.flavor1` / `flavor2`。世界観は既存仕様書 §2・§4）。テクスチャは 64×64 の特別仕様（陰影・光のにじみ・輪郭つき。2026-10-03、生成器 `BossDropTex64`）。超光速アクセラレータは、近未来の回路基板の 4 本の爪（隅の付け根から肘・手のひら・2 本の鉤爪）が掴む ∞ 字の金属の加速路を、2 つの光が尾を引いて走るアニメーション（24 コマ・1 Tick ごと。基板の配線にも光が流れる）。ルクシオニック・エッジ核は、厚い金の輪の上にひし形の結晶が外の列・内の列・中心の大結晶とぎっちり並び（吊るさない）、ときどき小さな結晶がきらめき、約 5 秒に 1 度 中心の結晶が強く光る（光条と光輪）アニメーション。ガリア重護装甲板は、暗いガンメタルの枠と重い鋲、蒼と赤が混ざる銀河模様の暗い装甲面（光沢・継ぎ目・一段高い中央の板）。歪曲力場発生炉は、立方体の金属枠の中で赤・緑・青の光が回りながら寄って混ざり（重なる所は足し合わせの色、芯は白）、枠が波打って歪み、全体が真っ白に光って元に戻るアニメーション（32 コマ・2 Tick ごと、1 周 3.2 秒）。黒死のナノコロニーは、胞子が増えて菌糸が伸び表面を埋め尽くし、膜が光った後に真っ黒に変わって下から崩れ落ち、小さな核から再び芽吹くアニメーション（40 コマ・2 Tick ごと、1 周 4 秒）。死蝶の光翼膜は、カラスアゲハを元にした紫基調の蝶（前翅に紫・ピンク・水色の鱗粉、後翅の輝く帯・三日月紋・尾状突起）が、止まっていてときどき羽ばたくアニメーション。時空剪定の針は、時計の輪の中で銀の針が紫の残像を引いて逆回転（反時計回り）し、背景に時計の数字（ローマ数字 I〜XII）がたくさん浮かんでは消えるアニメーション（48 コマ・2 Tick ごと、1 周 4.8 秒）。クロノ・ルーラーの心臓は、本物の心臓の形（大動脈弓・肺動脈幹の真鍮と銅の管）に大小さまざまな歯車（形からはみ出してよい）がかみ合って回り、拍動する（36 コマ）。ルミナルステラの追憶メモリは、星の結晶がピンクと水色の残影をいくつも重ねて漂う（40 コマ）。怨嗟なき零号コアは、カラフルな正十二面体が金と銀の 2 本の輪を土星のように付けてゆっくり回り、各面の色の光が体の後ろから筋になって漏れる（48 コマ）。崩壊特異点の残滓は、ノイズ（帯のずれ・色のずれ・砂嵐）が走ってひびが光り、砕け散って、また集まる（40 コマ）。

### 3.2a ティアと素材の決まり（2026-10-07 ユーザー指定「兵装はティアごとに応じた素材調整、AEC 級ボスの素材を使うのはティア 3 から、裏ボス素材を使うのはすべてティア 4 から」）

* **ボス素材**: T1・T2 の兵装は使わない。AEC 級（ルクシオン・ガリアフォート・メメントモリ: `ftl_accel`・`luxion_core`・`gallia_plate`・`distortion_gen`・`necro_colony`・`memento_wings`）は T3 から。裏ボス（ロストカタストロフィー: `memory_stella`・`purified_zero`・`singularity_remnant`）は T4 だけ（T4 の兵装はみな使う）。総司令機タイムルーラー（`time_needle`・`ruler_heart`）は T3〜T4 のまま。その素材で作る T3（クロノ・リピーター・ノヴァ・ランス・セラフ・スタッフ・タイムエリミネイター）はほかの T3 より強い: 持ち主の与えるダメージ ×1.5【仮】（同日ユーザー指定、`weapon/RulerForged`、説明に金色の「時空剪定の加護」）
* **圧縮素材**（追加拡張仕様書 §9.2）: T1 の兵装はブロック（Tier 1）まで、T2 はオーブ（Tier 2）まで、T3 からスター、T4 でコア
* 直したレシピ（同日）: ネクロシス・ニードルガン（ネクロコロニー → ナノメッシュのブロック 2）、ルクシオンセイバー（ルクシオン核 → 光子励起のオーブ、超光速アクセラレータ 2 → タキオンドライブ 2）、エクリプスブレード（零号コア → 黒死のナノコロニー）、スターフォール・ボウ（零号コア → ルクシオニック・エッジ核）、フロスト・ナックル（クロノスのオーブ → クロノメタルのブロック 2）、グラビティ・ハンマー（クロノスのオーブ 2 → クロノメタルのブロック 3）、T2 のプラズマ・チャクラム・プラズマ・フレイマー・プリズム・ライフル・スタティック・トラップ・レビテーション・ロッド・ボルテックス・キャノン（ルミナルスター → 光子励起のオーブ、数は同じ）
* T3 の兵装はみな AEC 級の素材を 1 つ以上使う（同日ユーザー指定「ティア 3 兵装はすべて AEC 級の素材を使うように」）。足したもの: アバランチ（黒死のナノコロニー）・クアンタム・ブレード（ルクシオニック・エッジ核）・クロノ・リピーター（歪曲力場発生炉）・ノヴァ・ランス（ルクシオニック・エッジ核）・セラフ・スタッフ（死蝶の光翼膜）・タイムエリミネイター（超光速アクセラレータ）、各 1
* 兵装以外（背部ユニット・外装・コア）はこの決まりに合っている（T4 の背部ユニット・コアが AEC 級・タイムルーラーの素材を使うのは可）

### 3.4 T1 の兵装・ルミナルコア（2026-10-03 実装、`weapon/`・`registry/ModWeapons`）

* 共通（`TacticalWeaponItem`）: 内蔵バッテリーは NBT「Energy」。持ち物のルミナルコアから放電レートまで毎 Tick 足す（`WeaponPower`）。
  クリエイティブは電力・弾を使わない。クリエイティブのタブには満充電（弾・溶液も満タン）で並ぶ。保護対象には普通に `hurt` するので Eprotect の上限が掛かる
* GeckoLib: `geo/item/<id>.geo.json`・`animations/item/<id>.animation.json`（`animation.weapon.idle` / `use`、ディフレクターは `deploy` / `retract` も）・

### 3.5.6 兵装のカスタムアップグレード（2026-10-04 ユーザー指定「バニラのエンチャントのように兵装の要素として」。素材の割り当てと強化の場所は【提案】）

兵装強化台（`upgrade_station`、`upgrade/UpgradeStationBlock`・`UpgradeStationMenu`・`client/UpgradeStationScreen`）で、兵装の 4 つの能力を 1 回 +10% ずつ、上限 +1000%（能力ごとに 100 回）まで上げる（`weapon/WeaponUpgrades`、兵装の NBT `Upgrades`）。エンチャントテーブルのように、左に兵装と素材を置き、右の能力の行を押す。置いた物は閉じると返る。

| 能力 | 効き目 |
|---|---|
| 攻撃力 | 持ち主の与えるダメージ ×(1 + 0.1 × 回数)（利き手に持っている間。兵装の攻撃・技・通常攻撃・飛び道具のすべて。オーバーロードの倍率とは掛け算） |
| 攻撃速度 | 近接の攻撃速度 ×(1 + 0.1 × 回数)（属性） |
| チャージ・クールタイム | チャージ時間とクールタイム（技の待ち時間・連射の間隔・T4 の通常攻撃の間隔）を 1 / (1 + 0.1 × 回数) に |
| エネルギー容量 | 内蔵バッテリーの容量 ×(1 + 0.1 × 回数) |

* 1 回の材料: 兵装のティアのオーブ・スター・コアを 1 つ（T1・T2 はオーブ、T3 はスター、T4 はコア。クロノ・ルミナル・ナノの 3 系統と連携金属のどれでも。タグ `upgrade_orbs`・`upgrade_stars`・`upgrade_cores`）と、ティアの金属（兵装の組み立てレシピの金属: T1 アストライト・インゴット（`forge:ingots/astrite`）、T2 クロノ・フォートレス鋼、T3 ステラクロノダイム・インゴット、T4 ステラクロノダイム・ブロック）を 10 個から、その能力を上げるたびに 1.1 倍（切り上げ: 10・11・13・14…）。金属は持ち物から引く。クリエイティブは材料なし
* 兵装強化台の作り方（作業台）: ` L ` / `AEA` / `AWA`（L = ルミナルクリスタル、A = アストライト・インゴット、E = エンチャントテーブル、W = 兵装作業台）
