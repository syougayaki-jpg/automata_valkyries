# 戦術兵姫 GUI・AI 決定事項 (SPEC_VALKYRIE_GUI_AI.md)

2026-10-04 にユーザーへの質問で決めた、戦術兵姫（エンティティ）の GUI・操作・戦闘 AI・日常/感情 AI・保護の方針。
数値・素体タイプ・ハードポイントは全体仕様書 §3、日常/感情 AI の元案は拡張仕様書 §12、見た目・動きは [`DESIGN_VALKYRIE_VISUAL_DB.md`](DESIGN_VALKYRIE_VISUAL_DB.md)。
ここに書いていない細部（数値・文言・見た目）は実装時に仮で決め、【仮】と書いてユーザーに確認する。

## 1. 操作

| 操作 | 結果 |
|---|---|
| 素手・普通のアイテムで右クリック | メニュー画面を開く（§2） |
| 好物・リペア剤などを持って右クリック | 渡す（同調率・修理。拡張仕様書 §12.1） |
| しゃがみ右クリック（頭を狙う） | なでる（同調率が少し上がる。1 日の上限付き【仮】） |
| しゃがみ右クリック（体を狙う） | 追従 ↔ 待機の切り替え |

- 頭か体かは、視線と当たり判定の交点の高さで分ける（目の高さ付近 = 頭）
- 指揮用のアイテム・一括指示キーは作らない（ユーザーが選ばなかった）

## 2. GUI

全体のテーマ: **ホログラム・発光線**。暗い半透明の地に、コアの色の発光線と角ばった枠（兵装の背景演出と揃える）。

### 2.1 メニュー画面（タブ）
- **換装**（ハードポイント画面、§2.2）
- **状態**（§2.3）
- **作戦指示**（§2.4）
- 会話タブ・記録（図鑑）タブは作らない

### 2.2 換装画面（Tactical Assembly）
- 中央に兵姫の 3D モデル（ドラッグで回転）。周りに体の位置に合わせてスロットを置く: Head / Chest / Legs（外装）、Backpack（背部）、Main Hand / Off Hand、Core、Logic Chip ×3、内蔵弾薬庫（4〜8 枠）
- 表示する数値（全部）:
  - HP / シールド / 電力（現在値と最大値のバー）
  - 積載重量と上限（超えたら赤）
  - 攻撃力・防御・速度（装備込みの合計と、装備前との差 +/-）
  - 同調率と、装備一式の毎 Tick の消費 FE
- 内蔵弾薬庫は**弾薬・修理剤専用**。お掃除で拾った物は別の一時枠で運ぶだけ（プレイヤーは触れない）

### 2.3 状態タブ
- 名前（変更欄）・素体タイプ（V/S/H/C）・性格とその説明
- 戦績: 撃破数・稼働時間・一緒に倒したボス
- 今の気分（表情）と、同調率の履歴（最近の増減と理由）

### 2.4 作戦指示タブ
- **行動モード**: 追従 / 待機（その場に留まる） / 拠点防衛 / 巡回・自由行動
- **拠点の設定**（ここにまとめる）: 「今いる場所を拠点に」・防衛半径・巡回範囲、お掃除の除外リスト。充電台は拠点の範囲内の物を自動で見つける
- **交戦規定**（細かく設定）:
  - 方針: 積極的（見つけた敵対モブは全部撃つ） / 反撃（自分や持ち主を攻撃した相手だけ） / 非戦闘
  - 狙う優先順: 近い順 / HP が低い順 / ボス優先 / タレット・警報優先（拡張仕様書 §10.3）
  - 追う距離（持ち主から何 m まで追うか）・射撃時に保つ距離
  - 下がる基準: HP・電力が何 % で後退するか、弾切れ時に近接へ移るか

### 2.5 HUD・頭上
- **HUD**: 画面左上に、追従中の兵姫を最大 4 体、顔アイコン＋HP / シールド / 電力の細いバーで縦に並べる。常時表示、設定で消せる・位置を変えられる
- **頭上**: 近づいたときだけ名前＋HP/シールドの細いバー。感情アイコン（♥ や ！）を短く出す

## 3. 戦闘 AI

- **攻撃対象**: 敵対モブとクロノゲイザー、持ち主や自分を攻撃した相手。他のプレイヤーは PvP 設定に従う
- **戦い方は持った兵装で自動に変わる**: 近接兵装なら詰めて斬る、射撃兵装なら距離を取って撃つ。素体タイプで立ち回りの癖が変わる（S は詰めが速い、H は前に立つ等【仮】）
- **機動**: ブーストで飛び回る。スラスター噴射の短いダッシュ・回避・ジャンプからの滞空射撃。背部ユニットで性能が変わる（常時飛行はしない）
- **防御行動**:
  - 飛んできた矢・弾を横ステップで避ける（確率・クールタイム付き）
  - 偏光シールド装備時は構えて受ける
  - HP・電力が下がる基準（§2.4）を割ったら後退して自己修理・充電を優先
  - **持ち主をかばうのはシールド持ちだけ**: 持ち主が瀕死（HP 20% 以下）のとき前に出て障壁を張り、「絶対障壁、展開！」（拡張仕様書 §12.3）を言う
- **連携**（簡単な連携）: 同じ敵を狙う、後衛（射撃）は前衛（近接）の後ろに立つ、攻城の防衛円陣（拡張仕様書 §10.3）
- **連れ歩き**: 追従は 4 体まで。拠点には何体でも置ける
- **味方への攻撃**: 持ち主・味方（同じ持ち主の兵姫・持ち主のペット）の攻撃は当たらない。兵姫の攻撃・範囲攻撃も持ち主と味方に当たらない
- **持ち主から離れたとき**（追従中）:
  - 24 ブロック以上離れたら持ち主のそばへテレポート（演出付き）
  - 持ち主の次元移動に付いてくる（ネザー・エンド・回想のディメンションも）
  - 持ち主が乗り物に乗ったら、空いていれば同乗、空いていなければブーストで並走

## 4. 日常・感情 AI

- **日常行動**（拡張仕様書 §12.2 の 3 つ＋自己充電）: 腰掛け・足ぶらぶら / お掃除（拠点から半径 12m、除外リスト以外を全部拾って最寄りのチェストへ） / 作業の見守り / 電力が減ったら自分で兵姫用充電台へ行って充電・整備（充電中は整備モーション）
- **兵姫用充電台**（新しいブロック）: FE を受け取る。兵姫が座って充電する
- **感情表現**: 顔のテクスチャ差し替えの表情（通常・笑顔・怒り・眠い等【仮】）＋仕草（喜ぶ・しょんぼり等）＋頭上の感情アイコン
- **セリフ**: 頭上に短い吹き出し＋同じ文をチャットにも。音声ファイルは無し（効果音だけ）。→ 拡張仕様書 E0.3「ボイスの再生方法」はこれで確定
- **性格**: 素体タイプごとに固定（V = 素直 / S = 元気 / H = 物静か / C = 理知的【仮】）。セリフは型ごとに用意し、同調率（低/高）で口調が変わる（拡張仕様書 §12.3）
- **同調率の効果**: 能力が少し上がる（100% で攻撃・速度 +20% まで段階的に【仮】） / 戦術級コードの解放（拡張仕様書 §13 の 30/40/50/70/100%） / セリフ・仕草が変わる
- **裏ボスのハッキング耐性は削除**（全体仕様書 §3.1・拡張仕様書 §12.1 の「100% で裏ボスのハッキング完全無効化」は取り消し）
- **お世話**: アイテムを持って右クリック（好物・リペア剤）、なでる（§1）。充電は兵姫用充電台・換装画面でのコア交換
- **お掃除の対象**: 全部＋除外リスト（作戦指示タブ）。→ 拡張仕様書 E0.3「お掃除ルーチンの対象」はこれで確定

## 5. 機能停止・保護

- **機能停止**（HP 0）: その場に座り込んで動かない。リペアで復帰。敵は狙わない（全体仕様書 §0.2-C）
- **保護**: 兵姫のデータ（装備・同調率・名前・戦績など）を常にバックアップする。通常のダメージは受け、HP 0 で機能停止する（被弾上限はかけない）
  - **完全な保護は胸のコアがステラ・ジェネシス・オメガのときだけ**（全体仕様書 §7.1「即死・ハッキング完全無効化」。2026-10-04 ユーザー指定）: 即死（kill / die / HP 0 への書き換え / 1 撃 100 万以上か無限大・NaN のダメージ）を受け付けず、消去も拒否し、消されたら自動で戻す
  - オメガコアの強さの目安（2026-10-05 ユーザー確認）: 超絶抹殺の棒までは耐える（蘇る）。終焉の魔杖の終焉機構は耐える・耐えないの水準ではないので、耐えさせる対処はしない
  - **オメガコア無し**: 即死は通常の HP 0 と同じく**死亡モーション（膝が折れて前へ崩れ、座り込んでうなだれる。約 0.9 秒。コアがちらついて弱まる、火花と煙）から機能停止**（直せる）。他 MOD の**消去は受ける**が、バックアップは「失われた」として残り、**救済通信機**（`rescue_communicator`）で持ち主のそばへ呼び出せる。自動では戻さない
  - **新設の「オートマタヴァルキリー protect」で守る**（Eprotect とは別の仕組み。ユーザーの回答「オートマタヴァルキリー protect として即死消去を防ぎデータを保護バックアップから常に復旧する（JAVA エージェントで管理）」。2026-10-04 に「Eprotect に登録」と誤って書いていたのをユーザーの指摘で直した）
  - 層の分け方（2026-10-04 ユーザー回答）: **ゲーム内の層は常に動く**（兵姫のクラス自身での拒否・毎 Tick の見張りと復元。このMODだけで動く）。**Java エージェントは起動時に指定したときだけ**（`-javaagent`、開発では `-PwithValkyrieProtect`。LifeGuard などと同じ扱い）。エージェントは**兵姫専用の新しいもの**（`src/valkyrieprotect`）
  - バックアップ: **ワールドのセーブ（SavedData）と、ワールドのフォルダの別ファイル（兵姫ごと）の二重**。片方が壊されても戻せる
  - 復元先: **消えた場所。危険なら持ち主のそば**（奈落・溶岩・壁の中・読み込まれていない次元など。持ち主がいなければ世界の初期地点）
  - **Java エージェント側の管理も Claude が担当する**（2026-10-04 ユーザー指定。兵姫の保護に限る。Eprotect+・真抹殺の棒は引き続き Antigravity 側）

## 8. 実装状況

### 8.1 段階 1（2026-10-04）: 持ち主・作戦指示・追従・機能停止・保護
- 持ち主: 持ち主のいない兵姫を右クリックで起動して持ち主になる（墜落ポッドはまだ無いので仮。スポーンエッグで出した兵姫も持ち主なし）
- 行動モード（`entity/ValkyrieEntity.Mode`）: 追従・待機・拠点防衛・巡回。しゃがみ右クリックで頭（体の高さの上 22%）を狙うとなでる（ハートと喜びの音、2 秒笑顔）、体を狙うと追従 ↔ 待機。拠点防衛・巡回は切り替えた所が拠点（半径 12）。作戦指示タブができるまで拠点防衛・巡回を選ぶ操作は無い
- 追従（`entity/ai/ValkyrieGoals`）: 5 ブロックより離れたら歩いて追い、24 ブロックを超えたら持ち主のそばへテレポート（光の粒とブーストの音）。持ち主が乗り物に乗ったら空いていれば同乗、降りたら一緒に降りる。持ち主の次元移動に付いてくる。追従は 4 体まで
- 機能停止: HP 0・即死（die / kill / HP 0 への書き換え、HP を直に 0 にされたのも毎 Tick 見る）で死なずに座り込む（目を閉じた顔、ダメージを受けない、狙われない、AI 停止）。ナノマシン溶液（`nano_solution`）かリペアインジェクター（溶液 1 本）を持って右クリックで 20 回復して起きる
- 素手の右クリック（持ち主）: 表情を順に変える（確認用の仮の操作。メニュー画面ができたら置き換える）
- 胸のコア: 持ち主がルミナルコアを持って右クリックで入れ替える（仮の操作。換装画面ができたら置き換える）。ステラ・ジェネシス・オメガで完全な保護
- 救済通信機（`item/RescueCommunicatorItem`・画面 `client/RescueCommunicatorScreen`、2026-10-04 ユーザー指定で UI 化）: 右クリックで保存された兵姫のデータの一覧を開き、選んだ兵姫を呼び出す
  - 一覧: 自分が持ち主の兵姫（稼働中・機能停止・消去された・遠くにいる）と、持ち主のいない消去された兵姫（［未登録］、呼び出すと自分の登録になる）。名前・状態・次元と位置・HP、オメガコアは ◆。ホログラムの見た目、ホイールでスクロール
  - 呼び出せるのは消去された兵姫だけ（稼働中・遠くにいる兵姫を呼ぶと、同じ個体が二重になるため）。手に持っているときだけ受け付ける
  - **破棄**（2026-10-05 ユーザー指定「警告はだすが不要な戦術兵姫のバックアップを破棄できるように」）: 選んだ兵姫のバックアップを、警告の確認画面のあとで破棄する。二度と呼び出せない。稼働中の兵姫は保護を外して消し、遠くにいて読み込まれていない兵姫も、読み込まれたら消える（破棄した UUID をセーブに残す）。自分のと［未登録］だけ
  - **登録は 1 人 100 体まで**（`ValkyrieProtect.MAX_REGISTERED`。持ち主のいない兵姫を右クリックで起動するとき・［未登録］を呼び出すときに数える。失われたものも数える）
  - 作り方【仮】: レッドストーン 1・アストライトのインゴット 4・ルミナルクリスタル 1・コンパス 1
  - 2026-10-04 の「超抹殺の棒で消した兵姫を呼び出せない」の調査: 超抹殺の棒（抹殺の棒の全手段＋深い追い出し＋同じ個体の再参加拒否）の後も、バックアップは「失われた」になり呼び出せる（GameTest で確認）。呼び出せなかったのは持ち主のいない（スポーンエッグで出して起動していない）兵姫で、前の作りは自分が持ち主の兵姫しか呼ばなかったため。今は［未登録］として一覧に出て呼び出せる
  - 同日「超絶抹殺と終焉の魔杖は呼び出せなかった」の調査: どちらも抹殺の仕組み（`annihilate/AnnihilationExecutionAgent`）を使い、消した UUID の参加を拒否し、拒否した体を discard する。呼び出しは同じ UUID で戻そうとして拒否されていた。今は拒否されたら**新しい体を作り直し、新しい UUID でデータを移して**戻し、バックアップの記録も新しい UUID へ移す（`ValkyrieProtect.restore`）。抹殺の仕組みのファイルは変えていない
  - 2026-10-05 の即死 MOD 全部入り（Omni-Mobs 抜き）での確認と直し（ユーザー「全部修正して」）:
    - 確認できたこと: 抹殺の棒・Hyperlink・抹殺・IMDS・Shizuku Blade・More Avaritia・Witherzilla の即死はオメガコア無しなら機能停止 → 消去 → 救済通信機で呼び出せる。ManaitaMTK・Hyperlink・Witherzilla の Ultima Blade・IMDS の即死はオメガコアなら無視
    - **救済通信機の呼び出しは常に新しい UUID**（`restore(..., freshId)`）: IMDS は消した UUID を一覧に持ち続け、同じ UUID で戻すとすぐまた消していた。記録も新しい UUID へ移す
    - **ログの間引き**: 同じ兵姫・同じ操作（値は除く）は 5 秒に 1 行、黙った数を添える（IMDS は毎 Tick 撃ち込むのでログが埋まっていた）
    - **壊れた HP の直し**: IMDS は登録した UUID の getHealth を 0 に書き換えるので、バックアップに HP 0 が残り、呼び出すと入った途端に機能停止していた。保存の HP は実際の値（`DirectRead`）で上書きし、戻すときも 0 以下・無限大・NaN なら、オメガコア無しは機能停止（HP 1、修理で起きる）、オメガコアなら満タンで戻す（Claude の仮決め。ユーザーが選ばなかったので仕様の「即死 → 機能停止」に合わせた）
    - **オメガコアの兵姫への IMDS の入口を止める**（`mixin/compat/ValkyrieImdsMixins`）: IMDS の `remov` はフィールド直書きと Tick 一覧・追跡からの除外で消すので setRemoved の拒否をすり抜け、消える → 復元（新しい UUID）→ また消される、を 1〜3 秒ごとに繰り返していた。オメガコアの兵姫だけ IMDS の execute_* / remov / cleanAI / markForDead / forceRemove / forceNoAi を止め、IMDS の一覧からも 1 秒ごとに外す。オメガコア無しは今まで通り受ける
    - **Shizuku Blade・ECA も同じく入口で止める**（`mixin/compat/ValkyrieShizukuMixins`・`ValkyrieEcaMixins`。ユーザー「全部やって」）: Shizuku は `Ymsa.annihilate` / `physicallyRemove` / `wipeEntityFields` 等、ECA は `EntityUtil.remove` / `removeFromServerContainers` / `teleport` / `setHealth(0)` と隔離の開始を、オメガコアの兵姫だけ止める。ECA の出現禁止（種類ごとに隠して追加も拒否）と隔離の追加拒否は兵姫を全部対象外にする（オメガコア無しでも呼び出し・復元が数秒拒否されないように）
    - **クライアントから見えなくなる問題**（ユーザー「稼働中だけどプレイヤーからみえていない」）: Shizuku の即死は `broadcastClientErase` でクライアントへ「消えた」と HP 0 を直接送るので、サーバーには居るのに見えなくなっていた。オメガコアの兵姫には止め、Shizuku・ECA の即死の後に追跡を作り直して出現を送り直す（`ValkyrieProtect.resync`）
    - **No-Sugar の消しゴムも入口で止める**（`mixin/compat/ValkyrieNoSugarMixins`。ユーザー「ついでに修正して」）: 消しゴムは setRemoved を通らずに消し、消した UUID を「消去済み」に印して同じ UUID の追加も拒否させていた
