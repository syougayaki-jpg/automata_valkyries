# Omni型本体解体の準汎用化（2026-10-09）

対象：終焉・真抹殺・超絶抹殺が使う `ModProtectionBreaker`。

## 今回移した処理

- 対象を直接指し返し、別のエンティティを参照しない本体だけを捕捉する。
- 本体の終了メソッドを呼ぶ前に、本体自身の識別子（UUID型の id / uuid / uniqueId）と、本体・対象が直接参照する外部オブジェクトのクラスを保存する。
- 終了メソッドが代理参照を切っていても、捕捉済み本体に辞書による死亡フラグ・防御フラグ・残機・タイマーの解除を実施する。再確認で別のエンティティを参照していたりフィールドを読めなかったりすれば実施しない。
- 保存したクラスの静的コレクションから対象、本体、対象UUID、本体UUIDだけを取り除く。既存の StaticReferencePurger の削除拒否 ArrayList 対策を利用する。
- 死亡後に再登録されても、保存済みのクラスと識別子を使って再清掃する。
- 超絶抹殺も、専用対策が代理参照を切る前に準汎用の本体捕捉を行う。

固有のMOD名やFlashfurのフィールド名を探索条件に使わない。準汎用層は genericOnly でも動作する。

## 限界

直接参照で届かないレベル常駐管理クラスや、所有を特定できない共有キュー・独自保存形式は対象外。ディスクの一括削除、MOD全体のクラス走査、EventBusの置き換えは準汎用層へ移していない。専用対策は引き続き残す。

GameTest は独立した本体、代理参照を切る終了処理、削除を拒否する ArrayList、本体UUIDによる再登録、別個体の保存、共有本体の除外を再現する。実物 Omni-Mobs はクライアント参照を含むため専用GameTestサーバーでの検証対象にできず、実物の撃破・再起動後の復活阻止をこのテストだけで保証しない。

## 検証結果

`gradlew build` 成功。最終変更を含む `gradlew build runGameTestServer -PgenericOnly` は340件を実行し、追加テストを含む339件が成功。既知の `overloadT4AnnihilationDropsLootAndExp`（羊の経験値欠落）だけが失敗したためコマンド全体は失敗扱い。ログは `build/codex-core-generalization-generic.log`。
