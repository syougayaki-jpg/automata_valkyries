## 1. 参考にした作品について【確認】

* 『星の翼』（Starward）は、メカ美少女たちが 1対1・2対2 で戦う 3D 対戦アクション。開発 Game Blender、PC（Steam）・スマホ・PS5
* 遊びの骨格はアーケードの 2対2 ロボット対戦（「美少女版エクバ」と呼ばれる）。射撃と格闘を組み合わせ、ブーストで立ち回り、覚醒で一時的に強くなる
* 地上だけでなく、上下を含む **360° の空中戦**が持ち味
* 基本の攻撃は **メイン射撃・サブ射撃・メイン格闘・サブ格闘** の 4 つ。移動・防御は **ブーストダッシュ・ステップ・ジャンプ・ガード・カウンター**
* キャラクターごとにコストがあり、チームで共有する（コストシステム）。ロックオン攻撃が立ち回りの軸
* 覚醒は「星能爆発（スターバースト）」。ゲージを溜めて発動し、一定時間強化される。種類は 5 つ（格闘寄り・射撃寄り など）。発動中は大技（バーストアタック）が使える
* キャラクターは**役割（前衛・後衛）**で分かれ、近距離の格闘が得意な者・遠距離の射撃が得意な者がいる
* キャラクターの題材は幅広い（中華風・エルフ・魔女・全身武装のメカ少女 など）。「メカの統一感」より「一人ひとりの個性と遊びの役割」を優先している
* 評価で繰り返し褒められている点（レビュー・コラボ記事より）:
  * **モーションの一つひとつ**が格好いい
  * **戦闘中の後ろ姿**が格好いい（三人称の背後視点で常に見える面）
  * **必殺技の演出**が何度見ても良い（単純な「突撃」でも演出で格好よく見せる）
  * **武装の組み合わせのロマン**（例: 大きな重砲と刀の二刀流）と、**モードチェンジ**の気持ちよさ
  * 黒を基調にした本体に、**一色の強い発光色**（例: 青い炎）を差すことで、露出の多い衣装でも「格好いい」に寄せられる

> 公開情報から確かめられたのは上まで。シルエットの作り方・アニメーションの手法・エフェクトの色設計などの**制作の手法そのものは公開されていない**。
> 以下の §2〜§6 は、上の事実と、メカ×少女・アクションゲーム一般の原則から組み立てた**このMODのための設計方針**であり、『星の翼』の内部の作り方を説明するものではない。

## 2. 機械と少女のデザインの連携【原則】→【本MOD】

### 2.1 核になる考え方

1. **少女の素体が主役、機械は「着るもの・背負うもの・持つもの」**
   * 顔・髪・胴の柔らかい曲線（少女）を中心に置き、硬い面と直線（機械）を **関節・背中・脚・腕の外側** に足す
   * 機械が素体の輪郭を覆い尽くさない。素体の輪郭が 5〜7 割見えていると「少女」と読める
2. **柔と剛の対比**
   * 素材の対比: 布・髪・肌（柔らかい・艶がある）⇔ 金属・樹脂（硬い・縁がある）
   * 形の対比: 曲線 ⇔ 直線と角。細い腰・首 ⇔ 大きな肩部・脚部・背部ユニット
   * 大きさの対比: 小柄な素体に**大きすぎる武装**（ロマン）。武装の大きさで役割と強さを語る
3. **機能の理屈がある形**
   * 噴射口（スラスター）は後ろ・下を向く。放熱板（フィン）は外へ開く。装甲の継ぎ目（パネルライン）・ボルト・排気口・冷却ベントで「動く機械」に見せる
   * 光る部分には意味を持たせる（ルミナルコアの出力・同調率・状態）
4. **一人一つの題材（モチーフ）**
   * 例: 騎士・天使・猫・蝶・星・時計など、題材を一つ決め、装甲の形・飾り・エフェクトの色をそこから揃える
   * 題材は兵姫の素体タイプ（§2.3）と役割に合わせる
5. **後ろ姿で読ませる**
   * 三人称で一番長く見えるのは背面。**背部ユニット（翼・スラスター・浮遊パーツ）を一番の見せ場**にする
   * 背面のシルエットだけで誰か分かるようにする

### 2.2 部位ごとの配分（目安）【本MOD】

| 頭 | 顔・髪型（一番の個性） | ヘッドセット・アンテナ・耳型センサー・バイザー | Armor Frame: Head |
| 胴 | 体の線・衣装 | 胸部装甲・**胸のルミナルコアの光**・肩部装甲 | Armor Frame: Chest／Core（光で見せる） |
| 腕 | 手・細い前腕 | ガントレット・肘の装甲・手持ち武装の接続 | Main Hand／Off Hand |
| 腰 | スカート・腰の線 | 腰部装甲（スカート状の装甲板）・ホルスター | （外装の一部） |
| 脚 | 太もも・膝の線 | 脛・足首の装甲・足裏のスラスター・ヒール状の脚部 | Armor Frame: Legs |

### 2.3 素体タイプとシルエットの型【本MOD】

素体タイプ（[SPEC_TACTICAL_VALKYRIES.md](SPEC_TACTICAL_VALKYRIES.md) §3.2）ごとに、遠くからでも分かる輪郭の型を決める。

| 素体タイプ | 役割 | 輪郭の型 | 機械の付け方 | 動きの性格 |
|---|---|---|---|---|
| Type-V（汎用） | 万能 | 縦長の均整。背中に左右対称の翼型ユニット | 全身に薄く均等 | 素直で整った動き |
| Type-S（近接高機動） | 前衛 | 前傾・細身・**後ろへ長く伸びる**スラスターや装甲の尾 | 脚と背中に集中、胴は軽装 | 速い・溜めが短い・残像 |
| Type-H（重装甲） | 盾・砲台 | 横に広い。**大きな肩と脚**、低い重心 | 肩・脚・背中に厚く | 重い・溜めが長い・着地で地面が揺れる |
| Type-C（電子戦） | 後衛 | 浮遊パーツが体のまわりを**囲む**（ビット・リング） | 体は軽く、体から離れた浮遊パーツが主役 | 浮いて滑るように動く・手振りで指示 |

### 2.4 色の設計【原則】→【本MOD】

* **三色の決まり**: 基調色（面積の大部分）・副色（装甲の縁・差し色）・**発光色（一色だけ）**
  * 発光色はルミナルコアの色と揃える（光る部分＝エネルギーの流れ）。一体の中で発光色を何色も使わない
  * 黒・濃紺など暗い基調に、強い発光色を差すと「格好いい」に寄る（§1 の評価）。白基調なら発光色は淡くして縁を暗くする
* 素体（肌・髪・衣装）と機械の色をぶつけない。髪色と発光色を近づけると一体感が出る
* 敵（クロノゲイザー）とは色の系統を分ける（敵は冷たい赤・紫など。兵姫は各自の発光色）
* 【本MOD】光る部分は GeckoLib の `_glowmask`（既存の兵装と同じ仕組み）で描く。発光色は兵姫ごとに 1 色

## 3. モーション・アニメーション【原則】→【本MOD】

### 3.1 動きの原則

1. **予備動作 → 動作 → 余韻**（溜め・実行・戻り）。予備動作が短いほど速く、長いほど重く見える
2. **重さと慣性**: 機械部分は少し遅れてついてくる（追従・遅れ）。髪・スカート・リボン・ケーブルも遅れて揺れる
3. **止めの一瞬**: 大技・決めのポーズでは数 Tick 止めて見せる（「キメ」）
4. **後ろ姿の動き**: 背部ユニットは待機中も動かす（翼の開閉・スラスターの明滅・浮遊パーツの回転）
5. **地上と空中を分ける**: 地上は足で踏む、空中はスラスターで「浮いて滑る」。空中では脚を揃え、体を少し前に傾ける

### 3.2 動きの一覧と長さの目安（20 Tick = 1 秒）【本MOD】

GeckoLib のアニメーション名は `animation.valkyrie.<名前>`（兵装の `animation.weapon.*` と揃える）。長さは目安で、素体タイプで伸び縮みさせる（Type-S は短く、Type-H は長く）。

| 動き | 名前（案） | 長さ | 中身 |
|---|---|---|---|
| 待機 | `idle` | 60〜80 Tick ループ | 呼吸（胸がわずかに上下）、髪とスカートの揺れ、背部ユニットの小さな開閉、スラスターの明滅、浮遊パーツの回転 |
| 歩き | `walk` | 20 Tick ループ | 腕の振りは小さめ。機械の脚は踏みしめる |
| 走り | `run` | 12〜14 Tick ループ | 前傾、髪・装甲の尾が後ろへ流れる |
| 浮遊 | `hover` | 40 Tick ループ | 脚を揃え、つま先を下へ。背部スラスターが下向きに噴く |
| ブーストダッシュ | `boost` | 開始 3 Tick ＋ ループ | 開始で一瞬縮こまり、背部が一気に開いて噴射。体を大きく前傾、腕は後ろへ流す |
| ステップ（瞬動） | `step_left` 等 | 6〜8 Tick | 横へ素早く滑り、着地で膝を曲げる。残像（§4） |
| 着地 | `land` | 6 Tick（Type-H は 10） | 膝を曲げて受け、装甲が一瞬沈む |
| 近接 1〜3 段目 | `melee_1`〜`melee_3` | 各 8〜12 Tick | 予備 2〜3・振り 2〜3・余韻 4〜6。3 段目は大振りで止め 2 Tick |
| 射撃（片手） | `shoot` | 6 Tick | 腕を伸ばし、反動で肩が少し下がる |
| 射撃（両手・溜め） | `charge`／`fire` | 溜めは武装の時間、撃つのは 8 Tick | 足を開いて踏ん張る。撃つ瞬間に体が後ろへ押される |
| ガード | `guard` | 開始 3 Tick ＋ 保持 | 腕・盾・装甲を前に。背部が前へ回り込むと「機械で守る」感じが出る |
| 被弾（小） | `hurt` | 6 Tick | 上体がのけぞる。装甲から火花 |
| 吹き飛び・ダウン | `knockdown`／`getup` | 12＋16 Tick | 回って倒れ、スラスターで立て直す |
| モード切り替え | `transform` | 16〜24 Tick | 装甲・武装が展開・収納される。見せ場なので止め 4 Tick |
| 覚醒（バースト）発動 | `burst` | 24〜30 Tick | 胸のコアが強く光り、背部が全開。決めのポーズで止め 6〜8 Tick |
| 大技 | `special` | 40〜60 Tick | 予備（溜め）を長く見せ、決めの一撃で止める（§5） |
| 機能停止 | `shutdown` | 30 Tick → 保持 | 光が消え、膝をついて項垂れる（死亡ではない。仕様 §3.1） |
| 省電力スリープ | `sleep` | ループ | 座る・丸くなる。コアがゆっくり明滅 |
| 撫でられ・喜び等 | `emote_*` | 30〜60 Tick | 日常・感情 AI（[拡張仕様書](SPEC_TACTICAL_VALKYRIES_EXT.md) §12）用 |

### 3.3 骨組み（ボーン）の方針【本MOD】

* 人型の基本の骨: `root` → `body` → `head`／`arm_left`・`arm_right`（`forearm`・`hand`）／`leg_left`・`leg_right`（`shin`・`foot`）
* 揺れもの: `hair_*`・`skirt_front/back/left/right`・`ribbon_*`（待機・移動で遅れて揺らす）
* 機械: `backpack`（`wing_left/right`・`thruster_*`）、`armor_shoulder_*`、浮遊パーツ `float_*`（体の骨の子にしない＝体から独立して浮く）
* 手持ち武装は兵装アイテムのモデルを手の骨に付けて描く（兵装は既存の GeckoLib モデルを再利用）
* 交換できる外装・背部ユニットは骨ごとに表示を切り替える（ハードポイント §3.3 に合わせる）

## 4. エフェクト【原則】→【本MOD】

### 4.1 エフェクトの言葉

| 場面 | 見せ方 | 本MOD で使えるもの |
|---|---|---|
| 推進（浮遊・ブースト） | 噴射口から短い炎・光の筋。ブースト中は長く強く | `GLOW`・`SPARK` の粒子（`weapon/Fx`）、噴射口の発光（glowmask） |
| 残像（ステップ・高速機動） | 半透明の体の影を数枚残す | 兵装の残影の手法（`client/QuantumSlashRenderer` 等の重ね描き） |
| 射撃 | 銃口の閃光 → 弾・光線 → 当たった所の閃光と衝撃波 | `PunishmentBeamEntity`（光の帯）・`Fx.shockwave`・`SPARK` |
| 近接 | 刃の軌跡（三日月の斬撃） → 当たった所の十字の閃き | `Fx.slash`・`BladeAura`（刃の光） |
| 被弾 | 装甲から火花、シールドが削れると六角の欠片 | `SPARK`・`HEX`（六角の欠片） |
| ガード | 前面に六角の障壁が一瞬見える | `HEX`・`Fx.shockwave` |
| 覚醒 | 胸のコアから光が溢れ、足元に陣、体のまわりを光が巡る | `Fx.mandala`（陣）・`STAR`・`GLOW`・画面の色（`TwilightPacket` の仕組み） |
| 大技 | 溜め中に光が集まり、放つ瞬間に閃光・衝撃波・画面の色 | 兵装のチャージ演出と同じ組み立て（`ChargedWeaponItem`） |
| 機能停止 | 光が消える・火花が散る・煙 | `SPARK`・バニラの煙 |

### 4.2 エフェクトの決まり

* **色は兵姫の発光色を基本に**、白い芯を重ねる（芯＝白、外＝発光色）。敵の攻撃は別の色系統
* **重ね方**: 外の淡い光（大きい）→ 中の光 → 白い芯（細い・強い）。既存の兵装エフェクトと同じ三層
* **時間の配分**: 出る瞬間が一番明るく、短く消える。長く残すのは陣・残光だけ
* **量の上限**: 遠くからでも読める大きさにして、数で押さない（兵姫が複数いても重くならないこと）
* **自分の視点**: 一人称の画面を塞がない（自分の兵姫の大きな光は、近いときは淡くする）

## 5. 演出（見せ場）の組み立て【原則】→【本MOD】

『星の翼』の評価で目立つのは「必殺技の演出」と「モードチェンジ」（§1）。単純な行動でも演出で格好よく見せられる。

1. **溜め（予告）**: 光が集まる・音が高くなる・足元に陣。相手にも分かる予告にする
2. **決め（止め）**: 放つ直前に 2〜8 Tick 止める。ここでポーズと光を一番強く
3. **解放**: 閃光・衝撃波・画面の色・音を同時に
4. **余韻**: 光の粒が散り、背部ユニットが閉じる・放熱板から排気

【本MOD】既存の T4 兵装（終の黄昏『ラグナロク』の振り下ろし、星葬冠『ルミナス・レクイエム』の鎮魂歌など）の演出は、この組み立てで作ってある。兵姫の覚醒・大技も同じ型で作る。

## 6. メカらしさの表現【原則】→【本MOD】

* **動く機械部分**: 開閉する翼・放熱板、回る浮遊パーツ・歯車、伸び縮みする砲身、スライドする装甲。待機中も少し動かす
* **熱と排気**: 撃った後・大技の後に、放熱板が開いて蒸気（白い煙）を吐く
* **光の流れ**: 胸のコアから腕・背中へ光が流れる線（パネルライン）。電力の残りで明るさを変えると「状態が見える機械」になる
* **重さ**: 着地の沈み・踏み込みの土煙。Type-H は特に強く
* **音**: 起動音・噴射音・装甲の金属音・放熱音（バニラの音を組み合わせる。専用の音は【要確認】）
* **状態が見た目に出る**: 電力が少ない＝光が弱く明滅、シールドが割れた＝六角の欠片が散る、機能停止＝光が消える

## 7. Minecraft／GeckoLib への落とし込み【本MOD】

### 7.1 大きさ・解像度

* 背丈は約 1.6〜1.8 ブロック（プレイヤーと同じくらい）。当たり判定は 0.6 × 1.8 前後
* モデルは箱の組み合わせ（GeckoLib／Blockbench）。顔と髪は箱を細かく重ね、機械部分は大きな面で作る（対比が箱でも出る）
* テクスチャは 64×64 を基本、顔だけ細かく描くなら 128×128【要確認】
* 光る部分は `_glowmask` テクスチャ（既存の兵装と同じ）

### 7.2 既存の仕組みの再利用

| 欲しいもの | 既存の仕組み |
|---|---|
| 手持ち武装 | 兵装の GeckoLib モデル（`client/WeaponRenderer`）を手に持たせる |
| 刃の光 | `client/BladeAura`・`BladeAuraLayer` |
| 背中の大きな飾り・光輪 | T4 兵装の背の飾り（`client/RequiemBackdropClient`・`T4BackdropClient`・`GenesisBackdropClient`） |
| 粒子 | `particle/FxOptions` と `weapon/Fx`（きらめき・光の玉・衝撃波・斬撃・六角・星・陣など） |
| 画面の色 | `network/TwilightPacket`・`client/ClientTwilight` |
| 保護 | Eprotect（兵姫は保護対象。§3.1 の機能停止の仕組みと合わせる） |

### 7.3 ハードポイントと見た目の対応

| ハードポイント（仕様 §3.3） | 見た目 |
|---|---|
| Core（ルミナルコア） | 胸の発光部の色・明るさ・明滅（電力の残りで変える） |

## 11. 決定した見た目（2026-10-04 ユーザーへの質問で決定）

**素体はエレノアのモデルを土台に流用する**（`geo/entity/elenor.geo.json`・`client/ElenorModel` の骨組みと揺れの計算をコピーして作り変える）。設定上はボスのエレノアと関係無し。ボスのエレノアのモデルはそのまま残す（別モデル）。

* **残す要素**: 長い髪（3 段）となびき、アホ毛・横髪・リボン
* **変える要素**: スカートは残さない → **体にぴったりしたボディスーツ＋脚部装甲**。体の寸法・頭身も作り直す
* **大きさ**: 身長 1.6〜1.7 ブロック・5〜6 頭身（プレイヤーより少し小さく、頭は大きめで表情が読める）
* **テクスチャ**: 128×128（エレノアと同じ）。素体と装備は別テクスチャ
* **制作**: Claude が geo.json とテクスチャを生成スクリプトで作る（後から Blockbench で直せる形）
* **4 つの型の見分け方**: 体の骨組みは共通。髪型・髪色・目の色・服の色・型ごとの装甲で分ける
* **メカの見え方**: 素体は少女。装備（外装フレーム・背部ユニット）で一気にメカになる
  * 素体にも付いているパーツ: 胸のコア窓（ルミナルコアが透けて見える。電力で明るさが変わる）、耳のセンサーユニット（発光色の光）、スーツの発光ライン（腕・脇・脚）
* **装備の見た目**: 外装フレーム・背部ユニットはアイテムごとに専用の形を作り、素体の骨に取り付ける（換装が見た目に出る）
* **表情**: 8 種＋瞬き（通常・笑顔・照れ・怒り（戦闘）・悲しい・驚き・眠い・機能停止（目を閉じる））。顔のテクスチャを差し替える
* **目**: 瞳がうっすら発光（発光色のハイライト。暗い所でも見える、戦闘中は強く光る）
* **揺れ**: エレノア並みの髪のなびき（コードで計算）に、ブーストや急停止で大きくなびいて戻る動きを足す。横髪・リボン・アホ毛も少し揺れる
