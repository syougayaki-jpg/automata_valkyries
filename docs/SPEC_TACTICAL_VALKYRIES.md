## 1. プロジェクト概要
* **MOD名**: Tactical Valkyries (戦術兵姫 -Automata Valkyries-)
* **開発基盤**: ~~Minecraft 1.20.4+ / NeoForge~~ → **Minecraft 1.20.1 / Forge**（Forge Energy 標準準拠）
* **依存・連携ライブラリ**: Curios API (任意連携), `forge:` タグ（工業鉱石互換。元資料では `c:` タグ）
* **コアコンセプト**:
  * 『LittleMaidMob』にインスパイアされた、愛着・自律管理・生活感のある少女型ガイノイド。
  * 『TacticalFrame』にインスパイアされた、ハードポイント兵装・外装換装システム。
  * 標準工業MOD（Mekanism, Thermal等）とシームレスに直結するFE/RF電力インフラおよび配線不要の独自テレポート工業ライン。
  * 雑魚からチート級（時間停止・無敵貫通・概念消去）までの段階的ボス攻略。

## 2. 世界観と背景設定
* **ルミナルステラ文明**: 恒星光と空間歪曲エネルギーを束ねる「ルミナルコア」を開発した超高度文明。最終戦争により滅亡。
* **戦術兵姫**: ルミナルコアの暴走を防ぐため、有機知性体の感情エミュレータ（無垢な少女の外見・精神）を与えられた最終決戦型ガイノイド。
* **時空横断機構クロノゲイザー**: 時間律の歪みを検知し、破滅した文明を剪定・消去する冷徹な機械兵団。
* **フォール・カタストロフ**: 兵姫部隊が放った特異点自爆によって次元が破砕され、兵姫・クロノゲイザー双方の残骸がマイクラ世界へ漂着。

## 3. エンティティ仕様：戦術兵姫 (Tactical Valkyrie)

### 3.1 基礎パラメーター体系
| パラメーター | デフォルト基準値 | 備考 |
| :--- | :--- | :--- |
| **Base HP** | 40.0 (ハート20個) | 0で死亡せず**機能停止**（要リペア）【暫定統一 C】 |
| **Energy Shield** | 20.0 (最大HPの50%) | 電力を消費して秒間5回復。被弾時に優先削れ |
| **Base Armor / Toughness**| 4.0 / 2.0 | 外装フレーム装備で大幅上昇 |
| **Move Speed** | 0.28 | バニラ通常歩行(0.1)より大幅に高速 |
| **Max Payload Weight** | 50.0t | 超過で速度低下・ブースト消費2倍 |
| **Internal Buffer** | 100,000 FE | コア未装着・換装時用の一時予備電源 |
| **Max I/O Rate** | 50,000 FE/t | コアからの引き出し限界。実効放電レートは min(コア放電レート, 本値)【暫定統一 B】 |
| **Tactical Tick Rate** | 2 ticks | AIの索敵・行動判断周期（チップで1 tick化） |
| **Sync Rate (同調率)** | 0% 〜 100% | プレイヤーとの絆値。~~裏ボスのハッキング耐性に影響~~（2026-10-04 削除。効果は `SPEC_VALKYRIE_GUI_AI.md` §4） |

**状態遷移【暫定統一 C】**
- **機能停止**（HP 0）: AI 停止・行動不能。リペア（ナノリペア剤・リペアインジェクター等）で復帰。死亡・消去はしない。
- **省電力スリープ**（電力 0）: AI 目標をキャンセルし `SleepingPose`。給電されると自動復帰。

### 3.2 素体タイプ別初期分岐 (Type Branch)
* **Type-V [Valkyrie]**: 汎用バランス型。HP 40 / シールド 20 / 速度 0.28 / 積載 50t
* **Type-S [Striker]**: 近接高機動型。HP 30 / シールド 15 / 速度 0.35 / 積載 35t (瞬動距離特化)
* **Type-H [Fortress]**: 重装甲防衛型。HP 60 / シールド 40 / 速度 0.20 / 積載 85t (ノックバック無効)
* **Type-C [Caster]**: 電子戦出力型。HP 35 / シールド 30 / 速度 0.26 / 積載 45t (索敵半径40m)

### 3.3 兵装換装GUI (Tactical Assembly)
* **ハードポイント構成**:
  * `Core`: ルミナルコア専用スロット (FE/RF蓄電アイテム)。**外装の Chest とは別枠**【暫定統一 A】
  * `Logic Chips` (×3): AI特性拡張チップ (Precision, Intercept, Absolute等)
  * `Armor Frame`: Head / Chest / Legs
  * `Backpack Unit`: スラスター、連装キャノン、ECM、テザー発生器
  * `Main Hand`: 近接ブレード、レールガン、重粒子砲 (両手占有あり)
  * `Off Hand`: 偏光シールド、サブマシンガン、リペアインジェクター
  * `Internal Ammo Depot`: 弾薬・ナノリペア剤格納スロット (4〜8枠)

## 6. アーキテクチャ・実装ガイドライン（元資料: NeoForge 1.20.4+ → 本プロジェクト: Forge 1.20.1）

### 6.1 パッケージ構成案
**未受領**（元資料は見出しのみ）。現状の実装は以下:
- `com.automatavalkyries.protect` — eprotect（保護システム）
- `com.automatavalkyries.mixin` — Mixin
- `com.automatavalkyries.entity` — エンティティ
- `com.automatavalkyries.registry` — `ModEntities` / `ModItems` / `ModCreativeTabs`
- `com.automatavalkyries.client` — レンダラー等（`Dist.CLIENT` 限定）
- `com.automatavalkyries.gametest` — GameTest

### 6.2 主要ロジック設計要件
1. **兵姫の電力消費・同期 (`EntityValkyrie`)**:
   * **`Core` スロット**【暫定統一 A】の `ItemLuminalCore` が持つ `IEnergyStorage` を tick ごとに参照。
   * アイドル消費、ブースト移動消費、被弾時シールド回復消費をハンドリング。引き出しは実効放電レート【暫定統一 B】まで。
   * 電力が0のときは AI 目標をキャンセルし `SleepingPose` に遷移（省電力スリープ）【暫定統一 C】。
2. **モジュラーアセンブリの同期**:
   * 兵姫エンティティは専用の `IItemHandler` (Curios互換スロット構造) を保持。
   * 装備変更時、クライアントへ即座にカスタムパケット (`SyncAssemblyPacket`、1.20.1 では `SimpleChannel`) を送出して3Dパーツ描画（GeckoLib等推奨）を再構成。
3. **テレポート搬出入 (`ChronoMachineBlockEntity`)**:
   * 内部にターゲット座標 (`BlockPos`, `ResourceKey<Level>`) とアクセス面 (`Direction`) を保持。
   * tick 処理時にワールド内のターゲット `BlockEntity` を取得し、`IItemHandler` / `IEnergyStorage` に直接アイテム・電力を Push/Pull。
4. **チート級ボスの特殊判定**:
   * `EntityTimeRuler`: フェーズ移行時、プレイヤーに `ServerLevel` 側で移動停止・パケット抑制（または超低Tickデバフ）を付与し、特異点コア所持の兵姫のみ `travel()` を独自計算させて身代わり防御を実行。
   * 1.20.1 には Tick レート制御（`TickRateManager`）が無いため、時間停止は独自実装（§0.1）。

### 6.3 ダメージ加工の適用順【暫定統一 E】
1. 変換系: ガリア外装「50 以下 → 1」、ガリアフォート障壁「1 固定」（貫通特性を持つ攻撃はスキップ）

  * 飛来する敵の射撃弾、ミサイル、投擲物を検知し、通常射撃で撃ち落とす迎撃AIルーチンを強制有効化。

  * 即死攻撃、赤色予兆ライン、巨大範囲爆撃を検知した瞬間、攻撃を即時中断して最大推力で安全圏へ自律ステップ回避。
* **ロジック: リソースセーバー (`chip_resource_saver`)**:
  * 残弾数とルミナルコアの残量を常時監視。残量30%以下で消費電力を抑える省エネ戦闘ルーチンへ自動移行。

> 2026-10-06 ユーザー指定で追加（数値は【仮】）。ヴァンガード・リアガード・メディックは役割のチップで、同時に 1 つだけ挿せる。
* **ロジック: ヴァンガード (`chip_vanguard`, T1)**: 持ち主の前（2.5 m）に立ち、持ち主を狙う敵を優先する。持ち主から 10 m より先へは追わない。射撃なら持ち主と敵の間に立って撃つ。
* **ロジック: リアガード (`chip_rearguard`, T1)**: 持ち主の後ろ（3 m、敵と反対側）に立ち、援護射撃に徹する。届かなければ届く所まで寄るが持ち主より前へは出ず、弾切れでも近接へ移らない・持ち替えない。
* **ロジック: メディック (`chip_medic`, T2)**: 持ち主・味方の兵姫の HP が 50% を割ったら駆け寄り、ナノマシン溶液を 1 本使って回復（兵姫は修理、プレイヤーは 8 回復＋再生 II 5 秒）。持ち主・味方が持った武器の弾を持っていなければ、拾った物・弾薬庫から 32 個まで渡す（弾薬庫からは自分の兵装の弾は渡さない）。弓・クロスボウの矢にも対応。
* **ロジック: アタックセレクト (`chip_attack_mode`, T1)**: 1 枚をしゃがみ右クリックで「通常攻撃だけ ⇔ チャージ攻撃（技・溜め撃ち）だけ」に切り替える。
* **ロジック: タレット (`chip_turret`, T2)**: チップを持ってモブを右クリックするとその種類を覚え（8 種まで、しゃがみ右クリックで消す）、覚えた対象（無ければ敵対モブみな）を兵装の最大射程まで探す。通常・チャージ攻撃の最大射程に入って見えたら足を止めて撃つ（ステップ・回避もしない）。射程の外なら普段どおり詰める。
* **ロジック: ノータッチ (`chip_no_pickup`, T1)**（2026-10-07 ユーザー指定「物を拾わない設定のチップ」）: 落ちている物を拾わない（お掃除・ポーターの荷物持ちで拾わない）。預かっている物の片付け・チェスト間の運搬・リモコンの「運んで」「渡して」はする
* **ロジック: スカベンジャー (`chip_scavenger`, T1)**（2026-10-07 ユーザー指定「ノータッチの逆の落ちているアイテムを探すチップ」）: お掃除で探す範囲 2 倍。追従中も、持ち主のまわり 10 m の落ちている物（除外リスト以外）を拾って預かる。ノータッチとは同時に挿せない
* **ロジック: ポーター (`chip_porter`, T1)**（2026-10-06 ユーザー指定「アイテムを運んでくれるお手伝いしてくれるチップ」、運び方は全部をしゃがみ右クリックで切り替え）: 入れ物を右クリックで運び先を覚える（チェスト間のモードでは、しゃがみで運び先・普通で運び元。同じディメンションで 64 ブロック以内の物だけ使う）。
  * 拾った物を運び先へ: お掃除の運び先を、いちばん近いチェストから覚えた運び先に変える
  * チェスト間の運搬: 追従以外のとき、運び元の中身を拾った物の枠に入るだけ取り出して運び先へ入れる、を繰り返す
  * 持ち主の荷物持ち: 追従中、持ち主の持ち物がいっぱいなら、持ち主のまわり 8 m の落ちている物（除外リスト以外）を代わりに拾って預かる
  * 指示リモコンの「運んで」で運び先へ預かった物を入れに行き、「渡して」で持ち主に渡す（入らない分は持ったまま。「渡して」はチップが無くても効く）

### 7.6 空間調律器＆システムツール

#### ① 空間調律器『クロノ・チューナー』 (`tool_chrono_tuner`)
クロノリンクマシンのテレポート搬出入ルートを設定する専用ツール。

* **操作仕様**:
  * **スニーク＋右クリック (対象ブロック)**: 搬入出インターフェース（チェスト、タンク、給電ドック等）の座標と面をバインド。
  * **右クリック (クロノマシン)**: 記憶した座標データをマシンの空間入出力スロットへ瞬時に登録。
  * **空中でスニーク＋右クリック**: 保存されたリンク情報のクリア。

#### ② 零号機再起動パッチ (`item_zero_reboot_patch`)
* **用途**: 裏ボス『ロストカタストロフィー』討伐後に入手する素体修復用特殊パッチ。
* **使用法**: 給電ドックに安置した零号機素体に対し、右クリックで使用。
* **処理ロジック**: 怨嗟プログラムの完全消去、同調率（Sync Rate）初期値を100%に固定し、味方エンティティとして完全覚醒させる。
